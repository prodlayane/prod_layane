# prod_layane — твой маленький рабочий стол

Готовый статический сайт в стиле macOS. Работает без npm, сборки, серверной части и внешних ресурсов.

## Открыть

Открой `index.html` в браузере. Или запусти из папки проекта:

```sh
python3 -m http.server 8000
```

Затем открой `http://localhost:8000`.

## Подставить свои данные

В начале `script.js` находится объект `PORTFOLIO`: имя, описание, навыки, телефон, почта, Telegram и Behance. Пустые контакты не отображаются. Ссылки должны начинаться с `https://`.

Ниже — массив `PROJECTS`. Для каждой работы можно изменить название, описание, год, категорию и изображение. Положи свои файлы в `assets/` и укажи их относительные пути в `image`.

- `category`: `photos`, `videos` или `design`.
- `folder`: для фото — `nature` или `city`; для дизайна — `identity`, `posters` или `digital`; для видео — `motion`.
- Для настоящего видео добавь `video: 'assets/my-video.mp4'` и своё изображение-превью. Рекомендуется MP4 с H.264/AAC.
- `demo: false` убирает пометку «Демо-концепт» в просмотре работы. Когда добавишь собственные работы, убери или замени демонстрационные пояснения в `homePage()` и `categories`.

Текущие работы — авторские SVG-этюды для демонстрации интерфейса. Видео-примеры — анимированные иллюстрации с работающим воспроизведением, паузой и повтором. Реальные фотографии и видеозаписи не включены.

Обои находятся в `assets/wallpaper.svg`. Основные цвета, размеры и адаптивная версия — в `styles.css`.

## Что работает

- Папки рабочего стола, боковая навигация и Dock.
- Подпапки и фильтры по работам.
- Быстрый просмотр изображений и видео.
- Закрытие, сворачивание, разворачивание и перетаскивание окна за верхнюю панель (на компьютере).
- История переходов стрелками в окне.
- Поиск по разделам и работам: `⌘K` / `Ctrl+K`, стрелки и Enter.
- `⌘1` / `Ctrl+1` — обзор, `⌘2` — обо мне, `⌘3` — контакты.
- `Escape` — закрыть просмотр, меню или окно. Окно можно вернуть через Dock.
- Два оттенка обоев, необязательные звуки, сохранение этих настроек в браузере.
- Копирование почты после её добавления в `PORTFOLIO`.
- Мобильная версия, управление с клавиатуры и поддержка уменьшения анимации.

## Опубликовать

Загрузи `index.html`, `styles.css`, `script.js` и папку `assets/` на любой статический хостинг. Для GitHub Pages выбери публикацию из корня ветки с файлами сайта. Сборка и секретные ключи не нужны. Самостоятельно публикация не выполнялась.
